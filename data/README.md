# Участник 4: данные, нормативы и качество

Ваша зона: эта папка. Backend и frontend меняет участник 3.

1. Изучить обучающие видео и сформировать категории наблюдаемых событий.
2. Дополнить разметку: видео, тип события, начало, конец, подходящее правило.
3. Заполнить `rules.json` проверенными источниками Республики Казахстан.
4. Отделить проверочные ролики от данных, по которым команда настраивает модели.
5. Проверять ложные срабатывания, пропуски, таймкоды, доказательства и время обработки.

`rules.json` намеренно пуст: реальные нормативы ещё не исследованы. Не добавляйте выдуманные статьи и ссылки.
В live-режиме backend отклоняет результат ML2 с неизвестным `rule_id` и берёт текст источника из этого каталога.

Форма записи (значения в угловых скобках нужно заменить подтверждёнными данными):

```json
{
  "id": "<устойчивый идентификатор>",
  "title": "<название правила>",
  "visual_signs": ["<что именно можно увидеть на видео>"],
  "document": "<название нормативного документа>",
  "section": "<пункт или раздел>",
  "url": "<https-ссылка на проверенный источник>"
}
```

Храните исходные записи в `data/videos/`, локальную разметку — в `data/annotations.local.json`.
Оба пути исключены из Git. Не публикуйте банковские видео, кадры и тестовые материалы жюри.
Не отправляйте их или их описания во внешние облачные AI-сервисы.
