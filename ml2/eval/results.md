## 2026-10-18 — регрессия декодера PyAV

Версия: рабочее дерево на основе `2e8dd42`; контроль — его родитель `c53663e`.
Исправления: явное прежнее преобразование BT.601 и один поток декодирования.
Модели, пороги и шаг 0,5 с сохранены. Обучение не выполнялось.

- Четыре открытых видео, свежие детекции на обеих версиях; модели резидентные,
  их загрузка исключена из времени. Все прогоны завершены полностью без адаптации шага.
- Роли, наличие машинки/сейфа и число треков совпали в 4/4 случаях.
  Все 409 кадров проверяемой сетки и их исходные PTS совпали с контролем.
- Максимальное увеличение времени — 0,86%; ни одного случая свыше +10%.
  Между сериями наблюдался существенный разброс времени, поэтому снижение
  времени отдельных запусков не считается доказательством ускорения декодера.
- Реальный localhost `POST /analyze` в новом окружении: H.264/yuv420p MP4 без
  звука, 142,53 с; HTTP 200 за 49,365 с, worker 49,174 с; `events: []`,
  `X-Rules-Enabled: none`, заголовков неполноты нет. Включённых правил нет.
- Чистый Python 3.12.10 venv без system-site-packages: установка requirements
  успешна, `pip check` без ошибок; 142 теста прошли за 8,421 с.
  Модели взяты из существующего локального комплекта; inference без сети.
- Лицензии PyAV и фактической сборки FFmpeg зафиксированы в README.

Подробная таблица, факты и журналы остаются локально в игнорируемом
`cache/decoder_regression/REPORT.md`. Один неполный диагностический прогон,
прерванный Modern Standby, исключён; события сна подтверждены журналом Windows.
Приватные факты, кадры, видео и веса в Git не добавлялись. Новый коммит и push
в рамках этой проверки не выполнялись.

## 2026-10-18 — v8, геометрия и относительная глубина

База: `5aa5ff3`. Восемь открытых видео, исходный вариант, отражение и повороты
±20°. Контролируемый replay одних детекций выделяет влияние расстояний;
отдельно выполнены восемь полных perception-прогонов с новыми детекциями.

| Метод | Стабильность роли | У стола | У машинки | Max добавка replay |
|---|---|---|---|---|
| Текущий | 100% | 100% | 81,47% | — |
| Нижняя точка человека/опор | 100% | 99,77% | 89,57% | 0,011 с |
| A, автоматическая плоскость-прокси | 100% | 92,17% | 86,23% | 0,377 с |
| B, Depth Anything V2 Small | 100% | 86,23% | 70,28% | 2,394 с |

Метрики — macro agreement по 24 преобразованным случаям, не accuracy.
На исходных восьми видео роли не изменились. В полном конвейере A/B
недоступны в одном из шести преобразованных случаев из-за потери якорей;
на пяти общих случаях near-table: текущий 100%, A 82,49%, B 84,10%.
Максимальная добавка полного конвейера: A 1,075 с, B 3,258 с,
без однократной загрузки depth-модели (~8,85 с).

Подтверждённой калибровки пола нет; автоматически получены только гипотезы
по столу/якорям, в 5/8 исходных сцен использован affine fallback.
Relative depth не является метрической глубиной; стопы часто закрыты столом.
**Новый метод по умолчанию не включён:** время проходит warm-лимит +5 с,
но стабильность присутствия ухудшилась. Базовая геометрия и API сохранены.

Опциональный Small checkpoint Apache-2.0 закреплён ревизией и SHA-256,
скачивается/копируется только явным `scripts/download_models.py --depth-small`.
ML-инференс локальный, без обучения и новых зависимостей. Открытые кадры
просмотрены для QA с разрешения пользователя; закрытые входы не читались.
Тесты: 160. Подробности и команды: [v8/report.md](v8/report.md).
Приватные числовые артефакты, картинки и веса остаются в cache/ и models/.
