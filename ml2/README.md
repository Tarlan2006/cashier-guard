# Участник 2: ML2 — проверка и matching

Зона ответственности: `ml2/`, локальная модель проверки и сопоставления с правилами.
Сервис на порту 8002: `POST /match`, JSON по `contracts/ml2-request.schema.json`:

```json
{"schema_version": "1.0", "duration_sec": 42.0, "events": [], "rules": []}
```

Это пример формы; в live `rules` обязательно содержит проверенные записи участника 4.
**Сейчас вы получаете наблюдения ML1 и выбранные JPEG, а не исходный ролик.**
Backend не передаёт видео в `/match`. Если модели нужны другие кадры/клипы, согласуйте
расширение с ML1 и участником 3 заранее; оно пока не реализовано.

Ответ по `contracts/analysis-result.schema.json`: `verdict`, `violations`.
Каждое событие: `type`, `timecode_sec`, `description`, 1–3 `evidence_frames`,
обязательный для live **`rule_id`** из переданного каталога. Нет подтверждённых событий:

```json
{"verdict": "no_violation", "violations": []}
```

Недоступность, сбой модели или неполный анализ возвращайте ошибочным HTTP-статусом,
никогда `no_violation`. Проверяйте наблюдения по кадрам, объединяйте дубли, отбрасывайте
неподтверждённые предположения. Подтверждение текста первой моделью без просмотра
доказательств не является независимой проверкой.

Backend сам добавляет `rule` по `rule_id`. Не возвращайте выдуманные нормы и ссылки.
Если присылаете объект `rule`, он должен точно совпадать с переданным каталогом;
подменённый источник даст `ML2_RULE_MISMATCH`.
Таймкоды конечны и сохраняют дробную часть: событие и кадры `0 ≤ t < duration_sec`.
JPEG полностью декодируется; до 8 млн пикселей, 8192 по стороне, 4 млн символов base64.
До 100 событий и 32 MiB ответа. Детали и коды ошибок — `contracts/README.md`.

Адрес: `ML2_URL`. Connect 5 с, write 30 с, read 90 с, весь запрос максимум 120 с.
Общий бюджет backend290 с включает загрузку, очередь и ML1+ML2, дедлайн имеет приоритет.
Работа локально без облачных AI API; после установки зависимостей и весов интернет
для обработки не нужен. Передайте участнику 3 команду запуска, зависимости, веса,
требования к оборудованию и измеренную длительность. В `demo` ваш сервис не вызывается.
