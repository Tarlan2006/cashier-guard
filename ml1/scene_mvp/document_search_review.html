Поиск документа без рамки на каждом видео

Образец — отмеченный тобой документ из Х‑3. В Х‑1 и Х‑2 поиск выполнен автоматически по одному фиксированному участку этой камеры. Рамки A/B/C — только похожие участки, не распознанные удостоверения. При выборе моментов учтены сходство и изменения между соседними кадрами; движение само по себе не доказывает предъявление. Если нужного предмета здесь нет, это не доказывает его отсутствия во всём ролике. Деньги, бумага и руки могут дать ложные совпадения.

Для каждого кадра выбери рамку, которая действительно охватывает документ, либо «Ни одна». Это проверка найденных участков; повторно обводить ничего не нужно.
