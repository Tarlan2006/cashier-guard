Примеры предметов из разных видео

Это кандидаты, пока без подтверждённых меток. Выдели мышью один предмет целиком с небольшим запасом; если предметов несколько, сохрани отдельный пример для каждого. Выбирай «неясно», когда тип неразличим. Для «пустого участка» выдели область без целевого предмета. Пропускай неподходящие кадры. Оцени видимое, а не ожидаемое нарушение.
development — для настройки; heldout — отложенные видео, ответы моделей на них не подбирать. X-1 исключён. Модель здесь не запускается, данные никуда не отправляются.

Выделенный участок:

Разметка временно сохраняется в localStorage этого Safari. Для надёжного сохранения регулярно экспортируй JSON. Изображения и метки должны оставаться локально. Разметка не является выводом о нарушении.
